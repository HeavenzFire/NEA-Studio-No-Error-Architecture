## Flow Dynamics

### Primary Value Flow:
[Care Event] → [Value Minted] → [Surplus Generated] → [Medical Cleared] → 
[Trust Built] → [More Participation] → [More Surplus] → [Cycle Repeats]

### Debt Dissolution Flow:
[Obligation Detected] → [Priority Assessment] → [Medical First] → 
[Vulnerable Second] → [Continuity Enforced] → [Debt Metabolized] → 
[Proof Published] → [Ledger Updated]

### Adoption Acceleration:
[Local Success] → [Visible Proof] → [Trust Transfer] → [Rapid Replication] → 
[Network Effect] → [Neutrality Threshold] → [Forced Adoption] → 
[Global Paradigm Shift]

## Key Invariants

1. **Permanence Invariant**: Once continuity is established, it cannot be revoked
2. **Priority Invariant**: Medical/vulnerable always first — non-negotiable
3. **Transparency Invariant**: All dissolution must be provable in real-time
4. **Velocity Invariant**: Surplus must move — cannot remain idle
5. **Justice Invariant**: Flow to vulnerable is structural, not discretionary
