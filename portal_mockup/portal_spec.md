## 🛠️ TECHNICAL STACK

### Frontend
- **Framework:** React 18 + TypeScript
- **3D Rendering:** Three.js + React Three Fiber
- **State Management:** Zustand or Redux Toolkit
- **Styling:** Tailwind CSS + Framer Motion (animations)
- **Math Rendering:** KaTeX for LaTeX equations

### Backend
- **API:** FastAPI (Python) for simulation execution
- **Quantum Sim:** Qiskit integration (server-side)
- **Database:** PostgreSQL (user data, progress)
- **Auth:** JWT tokens + optional Web3 wallet (NFT crest)
- **Realtime:** WebSocket for cohort chat, live collaboration

### Deployment
- **Hosting:** Vercel (frontend) + AWS/GCP (backend)
- **CDN:** Cloudflare for global asset delivery
- **Analytics:** Plausible (privacy-focused) or self-hosted Matomo
- **Monitoring:** Sentry for error tracking
